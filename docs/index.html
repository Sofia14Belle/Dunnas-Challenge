Dunnas Challenge

Sistema de Controle de Entrada e Saída de Visitantes

🎯 Objetivo do Projeto

O Dunnas Challenge é um sistema desenvolvido para registrar e gerenciar visitantes de forma prática, permitindo controle de entrada, saída, histórico e relatórios. Criado para fins acadêmicos como parte do Projeto A3 da disciplina de Gestão e Qualidade de Software.

🚀 Pitch

“Uma solução simples e eficiente para controlar o fluxo de visitantes em qualquer ambiente, garantindo organização, rastreabilidade e facilidade no registro de informações.”

🛠 Tecnologias Utilizadas

  • Ruby on Rails
  • Docker & Docker Compose
  • PostgreSQL (banco de dados)
  • Git e GitHub
  • GitHub Actions (CI/CD)
  • Minitest + SimpleCov
  • GitHub Actions
